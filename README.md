# 古田土会計チャレンジプログラム 得点集計・プロジェクター投影システム

古田土会計チャレンジプログラムの得点集計、リアルタイム順位表示、プロジェクター投影、A4用紙印刷（原本デザイン再現）に対応したWebアプリケーションです。

---

## 主な機能

1. **得点入力・管理**
   - 参加チーム数: 基本9チーム（設定画面より増減・名称変更可能）
   - チャレンジ種目（No.1〜8、各最大30点）:
     - **水色グループ**: No.1 じゃんけん、No.2 割り箸切り、No.3 ピクチャーコミュニケーション
     - **黄色グループ**: No.4 ヘリウムリング、No.5 トラフィックジャム、No.6 Aフレーム
     - **赤色グループ**: No.7 スーパー神経衰弱、No.8 パイプライン
   - **カラー達成チェック**: 「それぞれ色のチャレンジ種目を必ず1つ以上チャレンジ」のルールを自動判定しバッジ・警告表示
   - **最終チャレンジ順位自動反映**:
     - 1位: 60点、2位: 50点、3位: 45点、4位: 40点、5位: 35点、6位: 30点、7位: 25点、8位: 20点、9位: 15点
     - 着順を選ぶだけで自動加算＆順位重複チェック

2. **リアルタイム順位表 (Leaderboard)**
   - 総合得点・種目別小計・最終チャレンジ得点・色達成状況をリアルタイム一覧表示

3. **プロジェクター投影モード (Presentation)**
   - 会場の大画面スクリーン投影用。大きなフォント、暗所で見やすいダークデザイン
   - **表彰式・順位発表セレモニー演出**:
     - 9位から1位まで順番に発表
     - ドラムロール音＆ファンファーレ（Web Audio API内蔵・外部ファイル不要）
     - 紙吹雪（Confetti）アニメーション

4. **A4印刷対応 (Print Friendly)**
   - ブラウザの印刷（`Ctrl + P`）でそのままA4出力
   - 原本の得点表デザインを忠実に再現した「チーム別得点シート（手書き白紙用も可）」
   - 「総合結果発表レポート」

5. **データ保護**
   - ブラウザの `localStorage` にリアルタイム自動保存（誤ってリロードしても安心）
   - JSONバックアップの保存・復元

---

## 起動方法

### ローカルでの利用
`index.html` をお好みのブラウザ（Google Chrome, Microsoft Edge等）でダブルクリックして開くだけで、インターネット接続不要でそのまま動作します。

### Vercel / Web公開
静的ホスティング（Vercel, GitHub Pages 等）にデプロイすることで、スタッフのスマートフォンやタブレットからどこでもアクセス可能です。
